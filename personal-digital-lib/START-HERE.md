# Data Science Digital Lib — Vardhi Edition

## Open the website
1. Extract the ZIP.
2. Open the `personal-digital-lib` folder.
3. Double-click `index.html`. The dashboard opens directly; there is no separate welcome/login front page.
4. For full browser support, use VS Code with Live Server, or host the folder with GitHub Pages.

## Main files
- `index.html`: the redesigned main dashboard and navigation sections.
- `main.css`: the new page structure, responsive layout, and visual theme.
- `script.js`: shared legacy interactions.
- `modules/Module_01.pptx` through `Module_05.pptx`: your uploaded study presentations.
- `images/vardhi-profile.jpg`: your profile photo.
